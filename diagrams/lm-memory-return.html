Memory Return

The heptagonal base loop closes at one marked vertex. A separate lifted interval has two distinct endpoints projecting to that vertex.

Scope

Declared illustrative regular cover p:ℝ→∂P₇, p(t)=the constant-speed polygonal boundary point at t mod 1. The chosen lift t↦t runs from 0 to 1, so the deck defect is translation +1. Base closure does not identify lifted endpoints. This is a cover-space witness, not a general definition of memory.

§3, Lifted endpoint defect; §5, The Memory Return datum
