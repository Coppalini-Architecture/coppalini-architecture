Construction

Vertices 0 through 7 lie on an editorial octagon; these are two four-phase occurrence windows. All 28 edges of K₈ are drawn once and colored by a seven-round perfect matching partition. The partition uses vertex 7 as the round-robin distinguished vertex and residues 0,…,6 modulo 7. Each round contains four disjoint edges.

Scope

A finite combinatorial diagram. Vertex positions and edge crossings have no metric or physical meaning; relation set and scan order retain their separate offices.

Source location

Complete pairwise relations; Seven-round one-factorization
