    Method and boundaries
    This is a descriptive research audit. HIF transfer remains unassigned; an optional endpoint retains its declared assay and isoform. No medical recommendations are generated.

    Browser limits and receipt scope
    Browser inputs are limited to 2 MiB per file and 5,000 data records. Numeric CSV fields allow up to 4,096 characters and scientific exponents of magnitude at most 10,000. Metadata JSON integers must fit the browser’s safe integer range; use quoted decimal or rational strings for exact large parameters. Nonzero metadata numbers that underflow to zero are rejected. Pressure must be positive in absolute kPa; no upper pressure threshold is imposed. These resource limits do not change arithmetic within the accepted range.
    All fractions, bounds, and verdicts use exact BigInt arithmetic. Eta is an approximate display value. WebCrypto hashes bind the bytes selected or entered when available; unavailability is recorded explicitly. The browser receipt identifies this browser kernel and does not claim to execute or hash the Python kernel. Unedited files retain their original byte hashes, including line endings and any UTF-8 byte-order mark. Files edited in the text boxes receive hashes of their edited UTF-8 text.
    Extra source columns are retained as text in the extra-fields record. Spreadsheet software may interpret imported text beginning with formula characters; inspect CSV as text when source fields are untrusted.
