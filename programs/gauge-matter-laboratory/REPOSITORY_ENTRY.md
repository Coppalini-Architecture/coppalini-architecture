# Gauge & Matter Laboratory · Clear Onyx v0.5.2

6 November 2026. The original standalone executable HTML, full module source, build script, manifest, evidence notes, and automated tests appear in this directory without remodeling their implementation.

Open `clear-onyx-gauge-laboratory-v0.5.2.html` in a browser. To reproduce the build, install Node.js, run `node build.mjs`, then `node tests/check-manifest.cjs`, `node tests/check-v05.cjs`, `node tests/check-v042.cjs`, and `node tests/check-browser-bootstrap.cjs`. Successful actual outputs from this packaging session are recorded as `verification-check-*.txt`.

The simulation is a declared finite computational model. Its gauge, lattice, and mass checks establish mathematical and numerical properties of that model at specified resolution; they do not establish independent empirical measurement of a real particle system.
