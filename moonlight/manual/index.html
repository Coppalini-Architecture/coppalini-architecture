MOONLIGHT / user manual

Read the ring. Keep the lift.

MOONLIGHT is an exact finite reader. Its finite register gives a unique Chinese-remainder address from four phase residues and 137 iris residues. Its lift law is exact: F4(r,z)=(r,Laxz). The visible phase returns; the carried axial address and its receipt do not. This manual keeps the phase turn, Riemann logarithmic variable, and axial lift distinct.

03 / finite address

Four phase · 137 iris · 548 address

§16 / Metric Mirror Symmetry μ4 = {1, i, −1, −i} · μ4 × μ137 ≅ μ548 · ℤ/548ℤ ≅ ℤ/4ℤ × ℤ/137ℤ

Pick one four-phase value and one iris value. The Chinese-remainder address is the unique class a ∈ ℤ/548ℤ with the selected residues.

The Iris Dome renders the exact display adapter (q,s) → a: four phase bands, 137 iris sectors per band. Its map comes from this register, not from a counted image.

04 / Λ carriage

The same visible phase, a different retained address

  1. Fix T = 2 log Φ.
  2. Write the lift as Λ = (k + u)T, with deck address k ∈ ℤ and quotient position 0 ≤ u < 1.
  3. Read the visible dial W(Λ) = exp(2πiu). It returns when k advances by one; the receipt does not.

The discrete escapement form is F4(r,z) = (r,Laxz): the visible ring returns while the axial lift advances.

The source definition Λ(z) = log(Φ / |χax(z)|) requires axial input z. This manual computes the normal form once k and u are supplied; it does not fabricate z.

07 / shared Λ receipt

One portable read for independent readers

(source, T, u = [Λ], k, Λ, delta, reader), with Λ = (k + u)T and 0 ≤ u < 1

Independent readers can agree on the source, quotient position u = [Λ], deck address, lift representative, reader, and witnessed Difference. A new reader may recompute the finite 548 address and the Λ normal form without claiming an adapter not carried by this record.

08 / display boundary

The dome remains an application layer.

D4 retained

A dome may display an iris index, a four-phase state, an A8 seam, or a visible Λ dial. The display does not supply a map V → E, and no display result feeds back into M. Those relations require their own typed adapter and receipt.

Manual rule: the ring returns; the carriage continues; the receipt keeps the completed turn.
