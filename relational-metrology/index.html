Relational Metrology

Relation token: I. The reader instantiates supplied literal fields and evaluates right reading − left reading with exact decimal integers.

input literals → instantiated relation → outcome

Output is limited to the instantiated relation outcome. The same supplied inputs give the same exact result in any window. No value is supplied for an uninstantiated or unobservable relation. No interpretation is attached.
