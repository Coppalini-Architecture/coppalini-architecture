# Gauge & Matter Laboratory v0.5.6 — public audit record

## One declared signal frame

The laboratory now begins with seven literal display coordinates:

`FIELD / PLANE · COLOUR / COMPONENT · MEANING · MEMORY · MOTION · CHECK · SCOPE`

The selected model supplies these values. The frame changes for both live carriers and the five mounted study readers.

- Brightness reads the declared magnitude or density.
- Colour reads the selected model's phase, component, sign, quadrature, correlation, or registry coordinate.
- Shape and filaments read declared transport or spatial structure.
- Retained samples make the finite session history inspectable.
- Only the SU(3) carrier uses literal RGB as the three colour-basis populations.

This is a presentation and interface repair. It does not turn every displayed model into an SU(3) field or assert a common physical equation.

## Study integration

Λ Mirror, real signed 1D Φ⁴, hydrogen, helium, and water each provide a source-local signal object and local anchor. The build parses that object into the selected Study Reader mount. The sandboxed study owns its live controls and receipts; the outer frame names its declared contract only.

| Study | Retained boundary |
|---|---|
| Λ Mirror | a real-slice ζ/Ξ display with analytic, planar, and registry mirrors kept distinct; not an RH certificate |
| Real 1D Φ⁴ | signed field and fixed boundary sector; reflection compares sectors without field averaging; finite reader only |
| Hydrogen | coherent orbital state field and probability current; not an electron trajectory or emitted light |
| Helium | exchange-symmetric configuration-space slice; not electron paths |
| Water | a hydrogenic two-centre, eight-channel display; not molecular-orbital or electronic-structure energy |
