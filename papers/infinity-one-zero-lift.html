Abstract

This paper constructs an exact normal form for projective return with retained occurrence. A unique projective involution exchanges infinity and one, fixes zero, and admits an order-four complex lift. Explicit coordinate adapters connect these operators to the Coppalini root algebra. The axial escapement returns its phase every four steps while advancing the cycle address. Two successive cycles supply eight distinct occurrences and all 28 pairwise comparisons, resolved into seven four-edge matchings. For a fixed unit reference, an agreement scalar and the signed comparison record reconstruct the normalized state exactly. The resulting normal form has an explicit inverse on its stated image, supported by written proofs, exact executable audits, and a retained finite Lean subcertificate.

Exact reconstruction

Return with the address retained

For a fixed unit reference m and a unit state r, the agreement a = mᵀr and signed record D = mrᵀ − rmᵀ retain the state. The phase p and cycle count c retain the occurrence address n = 4c + p. On the stated image, the normal form has the explicit inverse:
