## I. Strong experiential observations worth carrying

### 1. Orientation precedes correction

The Care / Help papers distinguish orientation from error.

A person, organism, or controller can already be moving coherently without
requiring intervention.

This anticipates a useful cognition rule:

\[
\boxed{
\text{Read orientation first; infer correction only when a real obstruction is
present.}
}
\]

### 2. Transition cost is real

The boundary / consent materials repeatedly identify a missing transition step
as a source of friction.

The useful abstract form is:

\[
\boxed{
\text{present state}
\to
\text{notice / preparation}
\to
\text{transition}
\to
\text{new state}.
}
\]

This should later be compared with task switching, motor preparation, prediction,
working-memory updating, and control-cost literature.

It is not yet a universal cognitive law.

### 3. Recognition can overload the output gate

The Architecture Overload note contains a strong information-processing
observation:

\[
\boxed{
\text{internal active structure}
>
\text{available transmission bandwidth}
}
\]

can produce output spillover even while the underlying structure remains intact.

The repair proposed there is bounded transmission and permission-sensitive
channel use.

This belongs naturally beside working memory, communication bandwidth,
attention, inhibition, and social consent.

### 4. Load needs somewhere to go

Rotational Medicine repeatedly returns to one operational observation:

\[
\boxed{
\text{cost without an available absorption / routing path}
\to
\text{coordination failure}.
}
\]

The strongest useful distinction is:

\[
\boxed{
\text{supported frame change}
\quad|\quad
\text{forced frame change}.
}
\]

A supported transition has time, prediction, consent, or incremental re-indexing.

A forced transition exceeds current absorption capacity.

This is phenomenological/control vocabulary, not a clinical diagnosis.

### 5. Re-indexing is different from damage

One early description of “rotation” is especially useful:

- local references may remain;
- previously automatic reuse paths may temporarily stop composing;
- fluency drops while the system re-indexes.

This is a potentially productive bridge to task switching, context change,
state-space remapping, reconsolidation, and cognitive control.

### 6. Emotion was already being treated as a Read

RM 1 contains the early proposal:

\[
\boxed{
\text{emotion = signal of structural stress rather than sole driver}.
}
\]

The later Read-seam work gives this a safer future form:

\[
\boxed{
\text{bodily / affective state}
\to
\text{available evidence}
\to
\text{comparison / action}.
}
\]

The neuroscience and affective-science pass will decide how far that adapter can
actually go.

### 7. Attention was already being treated geometrically

RM 1 describes attention as sharpening near threatened misrecognition and relaxing
when return feels secure.

That is not yet a theorem.

It is a useful phenomenological hypothesis to compare later with:

- salience;
- precision weighting;
- gain control;
- uncertainty;
- threat monitoring;
- attentional effort;
- confidence.

### 8. Care and Help are different control modes

The mature Care / Help distinction is one of the strongest conceptual products of
this early set:

\[
\boxed{
\text{Care holds an open trajectory.}
}
\]

\[
\boxed{
\text{Help intervenes when continuation genuinely requires intervention.}
}
\]

The important cognitive question is how a Reader distinguishes:

\[
\text{difference that can remain open}
\quad|\quad
\text{difference that requires action}.
\]

This maps naturally to confidence, cost-sensitive decision, autonomy, and
consent.

### 9. Further / Farther / Through is a valuable control grammar

The language note separates:

\[
\boxed{
\begin{aligned}
\text{Farther}&=\text{remaining metric distance},\\
\text{Further}&=\text{viability of continued traversal},\\
\text{Through}&=\text{path by which continuation is tested}.
\end{aligned}
}
\]

This is unusually clean.

It should be retained for later work on motor planning, executive control,
language, and path selection.

### 10. Return / Cut / Recognition is a procedural stance

The early lineage repeatedly uses:

\[
\boxed{
\text{Return first. Then Cut. Then Recognition.}
}
\]

This should remain separate from literal sensory causal chronology.

Its strongest present interpretation is methodological:

1. recover the reference;
2. make the bounded distinction;
3. certify only what the resulting comparison supports.

It is therefore compatible with, but not identical to, the later sensorimotor
cycle

\[
L_n\to O_n\to R_n\to\sigma_n\to L_{n+1}.
\]

## II. First-person phenomenology worth preserving exactly as first-person data

The boundary / consent text contains an unusually explicit self-report sequence:

\[
\boxed{
\text{word}
\to
\text{feeling}
\to
\text{context-memory}
\to
\text{admissibility / meaning organization}
\to
\text{deliberation}
\to
\text{response or pause}.
}
\]

That sequence should not be generalized to all people.

It is valuable because it gives the later cognition pass a real first-person
trace to compare against laboratory constructs.

Likewise, the request for a transition cue before an assumed action can be treated
as a self-described preparation requirement:

\[
\boxed{
\text{notice}
\to
\text{state preparation}
\to
\text{command / requested motion}.
}
\]

Again: first-person carrier, not universal law.

## III. Wave Grammar is the strongest matured experiential bridge

The early Wave Grammar drafts contain many aggressive physical identifications
that later source work correctly loosened.

The Calm Field v0.2 draft is the version to carry forward.

Its governing correction is:

\[
\boxed{
\text{useful comparison}
\not\Rightarrow
\text{shared mechanism}.
}
\]

Its operational loop is:

\[
\boxed{
\text{notice}
\to
\text{choose}
\to
\text{feel the result}
\to
\text{update}.
}
\]

Its six strongest human terms are:

- Silent Scope;
- Golden Ear;
- Hand on the Rail;
- House of Trust;
- Imposed Closure;
- Quiet Return.

These are reflective Reader terms.

They are not diagnoses or neural structures.

The line to retain is the simplest:

\[
\boxed{
\textbf{Read the condition. Make the smallest viable move. Keep the receipt.}
}
\]

## IV. Early claims to quarantine rather than delete

Several early texts used exact mathematical or physical names as though they were
already established human mechanisms.

Those should remain provenance, not active premise.

Examples include:

- Hang \(=\) SU(2);
- Stick \(=\) U(1);
- Chill \(=\) gauge freedom;
- emotion \(=\) gravity;
- brain-wave bands as a universal internal phase clock;
- Circle of Willis as a lossless holonomy equalizer;
- trust differentials as vascular variables;
- human relational recognition as quantum entanglement;
- surf barrel traversal as literal gauge holonomy;
- Tsirelson's bound as a human/surf load threshold;
- a universal physiological “gravitational attractor.”

The later Calm Field audit already performs much of this correction.

These early forms remain valuable as discovery history because they reveal which
distinctions the author was trying to name before the types were available.

## V. Namespace migrations to remember

### ∅

Final namespace:

\[
\boxed{
\varnothing=\mathsf{UNTYPEABLE}.
}
\]

Any early use of \(\varnothing\) as refusal, death, failed return, or an internal
machine value must be read as historical notation.

### Refusal

Final project control:

\[
\boxed{
2=\mathsf{Fold}=\mathsf{Refusal}.
}
\]

### Memory

Early “residue” formulations were productive but incomplete.

Final Memory claims require recoverability / sufficient receipt at the promised
resolution.

### Recognition

Recognition is a comparison / verdict.

It is not Motion, intention, object construction, or perfect knowledge.

### Clinical vocabulary

“Rotational Medicine,” “diagnosis,” “trauma reflex,” and similar early labels
should remain archival or reflective unless a future clinical module carries
population, measurement, evidence, uncertainty, and professional review.

## VI. What these texts anticipated before the formal work caught up

Collectively, the early experiential papers were already circling seven problems:

\[
\boxed{
\begin{aligned}
1.&\ \text{How does a Reader preserve orientation under change?}\\
2.&\ \text{How much transition can the present system absorb?}\\
3.&\ \text{When does Difference require correction rather than holding?}\\
4.&\ \text{How does confidence change the cost of continued checking?}\\
5.&\ \text{How does reciprocal recognition prevent one-way load?}\\
6.&\ \text{How does a result update the next read without overwriting history?}\\
7.&\ \text{How do words become control-relevant events inside an embodied system?}
\end{aligned}
}
\]

Those are exactly the right questions for the upcoming cognition / attention /
working-memory / language / experience pass.

- orientation before correction;

- bounded transmission;
- reciprocal read / one-way-load distinction;
- supported versus forced re-indexing;
- confidence as permission economy;
- Care versus Help;

- first-person word → feeling → memory → meaning → response trace;
- notice → choose → feel result → update.

**RETAIN AS HYPOTHESIS FOR LATER RESEARCH**

- attention as a geometry / precision read;
- affect as stress or viability evidence;
- frame change as re-indexing cost;
- relational reciprocity as control stability;
- experiential “rotation” as a useful phenomenological class.

**RETAIN AS PROVENANCE ONLY UNTIL A NEW ADAPTER EXISTS**

- direct SU(2), U(1), gauge, gravity, holonomy, Tsirelson, EEG, vascular, or
  quantum identities assigned to human experience.

## VIII. Present conclusion

These documents should not be injected wholesale into the next cognition section.

They should sit beside it as **early experiential field notes**.

Their enduring value is not that they solved neuroscience before the neuroscience
pass.

Their value is that they isolated several distinctions early:

\[
\boxed{
\text{orientation}
\quad|\quad
\text{transition}
\quad|\quad
\text{load}
\quad|\quad
\text{attention}
\quad|\quad
\text{confidence}
\quad|\quad
\text{consent}
\quad|\quad
\text{care/help}
\quad|\quad
\text{return}.
}
\]

The next pass can now ask which of those distinctions have native cognitive and
neural carriers.

Nothing needs to be promoted in advance.
