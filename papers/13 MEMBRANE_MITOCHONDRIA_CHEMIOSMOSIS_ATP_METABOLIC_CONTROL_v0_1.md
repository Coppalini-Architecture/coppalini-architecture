# I. The membrane is the first energetic boundary

A biological membrane is a selectively permeable molecular boundary.

Its minimum energetic office is:

\[
\boxed{
\text{compartment}_1
\quad|\quad
\text{selective membrane}
\quad|\quad
\text{compartment}_2.
}
\]

The lipid bilayer strongly restricts the free passage of ions and many polar
molecules.

Membrane proteins then provide controlled pathways for:

- ion flow;
- metabolite transport;
- active pumping;
- receptor signaling;
- electron transfer;
- ATP synthesis.

The membrane therefore makes a persistent Difference physically maintainable.

A concentration difference can survive because equilibration is constrained.

A charge difference can survive because ionic movement is constrained.

A chemical reaction network can use those differences because transport is
selective.

The biological boundary is active:

\[
\boxed{

}
\]

# II. Electrochemical Difference

For an ion of charge \(z\), moving from side 1 to side 2, define the molar
electrochemical free-energy change

\[
\boxed{
\Delta \widetilde \mu
=
RT\ln\frac{a_2}{a_1}
+
zF(\psi_2-\psi_1),
}
\]

where:

- \(R\) is the gas constant;
- \(T\) is absolute temperature;
- \(a_i\) is ionic activity;
- \(F\) is Faraday's constant;
- \(\psi_i\) is electrical potential.

The two terms are different physical reads:

\[
\boxed{
\text{chemical concentration Difference}
\quad+\quad
\text{electrical potential Difference}.
}
\]

Their sum determines the thermodynamic drive for that ion across the membrane.

At equilibrium for the selected ion:

\[
\boxed{
\Delta\widetilde\mu=0.
}
\]

Away from equilibrium:

\[
\boxed{
\Delta\widetilde\mu\neq0
}
\]

and a permeation pathway makes directed net transport possible.

The gradient is therefore a relation.

It is stored physical Difference across a boundary.

# III. Proton-motive force

For mitochondrial proton transport, let:

- \(p\): intermembrane-space / positive side;
- \(n\): matrix / negative side.

For a proton moving \(p\to n\),

\[
\boxed{
\Delta G_{H^+,p\to n}
=
RT\ln\frac{a_{H^+,n}}{a_{H^+,p}}
+
F(\psi_n-\psi_p).
}
\]

Define the proton-motive force in the inward-driving convention:

\[
\boxed{
\Delta p
:=
-\frac{\Delta G_{H^+,p\to n}}{F}.
}
\]

Using

\[
a_{H^+}=10^{-pH},
\]

this becomes

\[
\boxed{
\Delta p
=
(\psi_p-\psi_n)
+
\frac{2.303RT}{F}
(pH_n-pH_p).
}
\]

Thus:

\[
\boxed{
\Delta p
=
\Delta\psi_{\rm drive}
+
\Delta pH_{\rm drive}.
}
\]

A positive \(\Delta p\) in this convention supplies free-energy drive for
protons to return from the intermembrane side to the matrix.

The proton-motive force is the bridge between redox transport and ATP synthesis.

# XX. Respiratory control

When ATP-consuming processes increase:

\[

backpressure can slow respiratory flux.

This is physical feedback through shared energetic carriers.
